一、软件是干什么的
-------------------
一款专注于 PPT 放映 / 公开课 / 课堂教学场景的极简板书白板工具。
打开 PPT 放映时可在任意幻灯片上用触屏或鼠标做批注、翻页、选择缩放、画标准几何图形。


二、免安装版怎么用
-------------------
（绿色版压缩包步骤）
1. 把整个文件夹解压到任意位置，例如：
   D:\Programs\Inkboard\
2. 双击运行 "Inkboard.exe"。
3. 建议：在 exe 上 右键 → 发送到 → 桌面快捷方式，方便以后启动。

如果启动后 PPT 放映相关功能提示失败：
 - 请确认电脑已安装 Microsoft Office / PowerPoint。
 - Win10 1809 以后、Win11 全部版本都内置 .NET Framework 4.7.2，无需再装。


三、安装包版怎么用
-------------------
方式一（推荐，单文件）：
1. 下载 Inkboard-v6.0.0-Setup.exe（单个 exe，双击即装，无需解压）。
2. 按向导下一步即可；安装后桌面、开始菜单出现 "Inkboard" 快捷方式。
3. 从旧版 Ink Canvas（v5.x）升级：安装器会自动迁移 Settings.json、
   自定义图库（CustomShapes）等数据，并清理旧版快捷方式，无需手动操作。
方式二（zip 分发）：
1. 解压 Inkboard-v6.0.0-Portable.zip 到任意目录，双击 "Inkboard.exe" 即可运行。
2. 卸载：控制面板 → 程序和功能 → Inkboard → 卸载（不会删除你自己的图库和 Settings.json 配置）。


四、主界面 / 悬浮条图标说明
----------------------------
鼠标 / 指针  →  点击穿透（把画板藏起来，让鼠标操作正常）
颜色圆点    →  6 种预设画笔颜色（黑/红/绿/蓝/黄/白）
橡皮擦      →  左键在"矩形面积擦 / 笔画擦"之间切换
垃圾桶      →  清屏（点一下提示，再点一下确认）
选择        →  框选墨迹（可拖动、缩放、旋转）
图形        →  插入标准图形（三角/圆/方/线条等，可长按锁定持续画）
撤销 / 重做 →  撤销 / 重做刚才的操作
双指手势锁  →  双指缩放/平移/旋转 的开关，锁定防误触
白板        →  打开一张无限白色板书页（再点关闭）
退出 PPT    →  一键退出当前 PPT 放映
截图        →  截取屏幕任意区域
三滑杆      →  画笔粗细 / 识别 / 手指模式 快捷设置
笑脸（左上悬浮球）→ 展开/收起悬浮条，或右键设置、重启画板、查看快捷键


五、橡皮擦
----------------------------
左键点橡皮按钮：在"矩形面积擦 / 笔画擦"之间切换
 - 蓝色纯矩形图标    →  矩形黄金比面积擦（适合大块擦除）
 - 橙色+波浪图标     →  笔画擦（点到哪条笔画整条删除）
设置面板里的橡皮大小（5 档）都已经生效，分别对应 30/45/60/80/100 宽的竖矩形。


六、笔记滚动
----------------------------
屏幕右侧边缘（屏幕模式/白板模式）会出现一个竖胶囊：
 ▲ 上箭头 → 回到顶部
 ● 滑块  → 显示当前笔迹位置（越深=滑块越下）
 ▼ 下箭头 → 往下扩展新的空白区域
鼠标滚轮（光标在墨迹区域）：每次滚动约 10% 屏高。
注意：在 PPT 放映模式下，滚轮不会滚动笔记，而是穿透给 PPT 翻页（符合上课习惯）。


七、自定义图形（图库）
----------------------------
1. 先用"选择"框选墨迹，
2. 点悬浮条上的"存入图库"，
3. 之后任何时候点"图形 → 我的图形"即可一键粘贴。
4. 图库图形上可右键删除、按插入顺序排序。


八、选择后支持的操作
----------------------------
选中墨迹后：
 - 直接拖动 = 移动
 - 四角圆点 = 等比缩放（宽高一起变，字不变形）
 - 四边中点圆点 = 单轴缩放（只改宽或只改高）
 - 右上角旋转把手 = 旋转（默认每 15° 一档，设置里可以切回 45°/90°）
 - "存入图库" = 保存到图形快捷栏
 - 右键 = 删除 / 克隆一份
缩放快捷键（v5.1 新增）：
 - Ctrl+滚轮：有选区缩放选中内容，无选区缩放整屏批注
 - Ctrl+= / Ctrl+-：同上，主键盘与小键盘加减号均支持


九、快捷键
----------------------------
模式切换
  F1 　  鼠标模式（点击穿透，画板隐藏）
  F2 　  绘画 / 板书模式
  F3 　  橡皮擦（当前模式）
  Shift+F3  切换橡皮：矩形面积擦 ⇄ 笔画擦
  F4 　  选择墨迹

撤销重做
  Ctrl+Z   撤销
  Ctrl+Y   重做
  F12      重启画板（Ctrl+Shift+R，避免与其他软件冲突）

界面
  Ctrl+E   清空当前页（清屏）
  Ctrl+B   打开 / 关闭白板
  Ctrl+S   保存 / 导出当前截图

查看快捷键
  点左上笑脸悬浮球 → 右键 → 快捷键 → 查看快捷键


十、常见问题
----------------------------
Q1. 启动了什么都看不到？
 A. 程序启动后默认只显示一个笑脸小悬浮球在屏幕左上。点它展开工具条。
    若是安装/绿色版首次完全没显示，检查是否被 Windows Defender 拦截或托盘中。

Q2. 橡皮图标和原图标的线条好像粗细不一样？
 A. 已用 IconStroke=1.22 全局统一定义所有自制图标粗细，和原生 Undo/Redo 一致。

Q3. 自定义图形文件存在哪里？
 A. 程序运行目录 / CustomShapes 文件夹，每份一个 .isc 文件（WPF 原生 ISF 墨迹格式）。
    升级版本或换电脑时把整个 CustomShapes 文件夹拷过去即可。

Q4. PPT 放映模式下我滚动鼠标结果软件消失了？
 A. 已修复：是第 1 页 Previous() 调用 PPT COM 时抛的未捕获异常导致。若还是出现请反馈 Office 位数与版本。

Q5. 双指为什么不能缩放 / 平移笔迹？
 A. 请检查"双指手势锁"图标 —— 如果出现斜杠，说明已锁定；再次单击图标即可解锁。
